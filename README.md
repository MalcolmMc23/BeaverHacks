# 🦫 Beavers – Smart Task Management with Focus Mode

**Beavers** is a React Native mobile app that helps you stay productive by combining intelligent task management with focus mode features. Built with a clean, modern UI and personalized onboarding, it adapts to your productivity style and helps you maintain focus during work sessions.

## 🎯 Key Features

- 🎨 **Personalized Experience**  
  Custom onboarding flow that learns your:
  - Most productive times of day
  - Preferred rest days
  - Schedule structure preference (structured vs flexible)
  - Notification style (motivational vs minimal)

- 🔒 **Focus Mode**  
  Lock distracting apps during work sessions with customizable app blocking:
  - Popular apps like Facebook, Instagram, TikTok
  - Custom app additions
  - Flexible blocking schedules

- 🌗 **Dark & Light Mode**  
  Automatically adapts to your system preferences for comfortable viewing any time of day

- 📱 **Modern UI/UX**  
  - Clean, intuitive interface
  - Smooth animations
  - Accessible design
  - Native platform feel

## 🛠 Tech Stack

- **React Native** – Mobile app framework
- **Expo** – Development and build tools
- **TypeScript** – Type-safe development
- **AsyncStorage** – Local data persistence
- **React Navigation** – App navigation
- **Expo Router** – File-based routing

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Start the development server:
   ```bash
   pnpm start
   ```

3. Run on your device:
   - Scan the QR code with Expo Go (Android)
   - Scan the QR code with Camera app (iOS)
   - Press 'i' to open iOS simulator
   - Press 'a' to open Android emulator
